# Data Karir

Folder ini berisi data daftar kanal karir Karir:

- `daftar-link-karir.csv` — data mentah, satu baris per perusahaan
  (610 perusahaan per 15 November 2026), 13 kolom. File ini sumber
  kebenaran untuk isi data.
- `daftar-link-karir.xlsx` — data yang sama dalam format spreadsheet.

Kolom dan artinya ada di `../docs/METODE.md` (seksi "Kolom data").
Cara tiap kanal dicek ada di `../docs/METODE.md` juga.

## Cara memberi atribusi

Bila memakai data ini, cantumkan atribusi seperti ini (sesuaikan
formatnya dengan medianya):

> Data kanal karir dari Karir (https://github.com/adiprmx/karir)
> oleh ADIP RMX, berlisensi CC BY 4.0
> (https://creativecommons.org/licenses/by/4.0/).

Bila datanya diubah, sebutkan juga bahwa data tersebut sudah diubah
dari aslinya. Jangan memberi kesan bahwa ADIP RMX atau Karir mendukung
pemakaian tersebut, kecuali memang ada persetujuan.

## Catatan kejujuran data

Data ini dicatat pada tanggal cek per baris (kolom `tanggal_cek`).
Lowongan bisa dibuka atau ditutup setelah tanggal itu — data ini
tidak menjamin lowongan masih ada, dan tidak menjamin pelamar akan
diterima. Lihat batasannya di `../docs/METODE.md` (seksi "Batasan").
