# Dokumen

- `METODE.md`: cara tiap kanal karir dibuka dan diperiksa, arti 6 status, dan aturan kejujuran pengecekan.
- `TEMUAN.md`: daftar 22 lowongan target yang terverifikasi beserta syaratnya.
- `ARCHITECTURE.md`: alur data end-to-end, koleksi Firestore, lapisan baca dan tulis, dan keputusan arsitektur.
- `API.md`: dokumentasi tiap endpoint di `web/app/api`, parameter, contoh respons, dan kode error.

File `app.js`, `companies.json`, `index.html`, dan `styles.css` di folder ini adalah aplikasi statis lama (GitHub Pages). Versi itu sudah tidak live dan sengaja disimpan sebagai versi sebelumnya.
